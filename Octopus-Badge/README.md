# Octopus Badge

![Foto der Oktopus-Platine von beiden Seiten inklusive der drei benötigten Bauteile](/Octopus-Badge/Octopus-Badge.jpeg)

Easy PCB soldering project for educational purposes and makespaces.

Einfaches PCB-Lötprojekt für den Einsatz in Bildungseinrichtungen und Makespaces.

## Parts List

| Description                     | Quantity |
|---------------------------------|----------|
| RGB LEDs 5mm                    | 1        |
| Button (SMD)                    | 1        |
| CR2032 Battery Holder (SMD)     | 1        |
| CR2032 Battery                  | 1        |

You can find matching components on [blinkyparts.com](https://shop.blinkyparts.com/de/Einzelteile/).

Passende Bauteile gibt es bei [blinkyparts.com](https://shop.blinkyparts.com/de/Einzelteile/).
