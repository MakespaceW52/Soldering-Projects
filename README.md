# Soldering Projects
Easy soldering projects for educational purposes and makespaces.
For all projects, we provide Gerber files for production by PCB manufacturers, as well as KiCad project files for further modification and development.

Einfache Lötprojekte für den Einsatz in Bildungseinrichtungen und Makespaces.
Für alle Projekte stellen wir Gerber-Dateien zur Produktion über Platinenhersteller sowie KiCad-Projektdateien zur weiteren Bearbeitung bereit.
